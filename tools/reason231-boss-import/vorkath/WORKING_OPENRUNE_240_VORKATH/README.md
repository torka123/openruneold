# Working OpenRune 240 Vorkath cache

This directory intentionally contains no cache archives.

The active revision-240 `LIVE` and `SERVER` caches already contain every required Vorkath NPC, location, sequence, spot animation, model and Ungael region. Importing donor archives would add risk without adding an asset. The cache-change allowlist is therefore empty.

Vorkath is implemented through server code and native RSCM names. Cache integrity evidence is recorded under `docs/bosses/vorkath/`.
