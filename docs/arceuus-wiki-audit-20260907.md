# Arceuus Wiki and execution audit — 2026-09-07

The revision-240 registry contains 45 Arceuus entries, including Minigame Teleport. Teleport to Target belongs to the shared/default spellbook and is listed separately below. This audit distinguishes a registered definition, an executed handler, and verified OSRS behavior. A passing rune/catalog test alone is not evidence that a spell works.

The local policy deliberately removes quest requirements. Rune, Magic, item, target, and Prayer checks remain relevant. This is a documented server deviation from OSRS, not Wiki parity.

## Execution evidence and limits

- `ArceuusTeleportRuntimeTest`: all 13 actual Arceuus cast functions executed with real cache requirements and real rune consumption; destination coordinates checked. Separate tests cover Home's 22-tick channel, movement/combat/coroutine interruption, the 17-tick recent-combat boundary, shared persisted recharge and final teleport denial. Minigame tests execute both supported destinations, the actual menu selection, native persisted 20-minute recharge, interruption, invalid-destination rollback and Pest Control's level-40 combat requirement. Nine tests passed. `MinigameCacheAuditTest` independently verifies the native 951 component mapping and varp 888.
- `WardOfArceuusRuntimeTest` and `WardOfArceuusDamageTest`: real player hit modifier exercised with cache-classified demons, non-demons, an unknown source, active/expired effects, both buff-display preferences and integer rounding. Three tests passed.
- `ArceuusCombatCastRuntimeTest`: all seven registered target handlers execute with real rune checks and cast XP. Formula rolls and the final attack queue boundary are mocked, so this does **not** establish combat formula or animation-timing parity. Dark Lure follow/ownership/expiry/splash/cleanup tests use real NPC movement. Four tests passed in the root integration run.
- `ArceuusMarkRuntimeTest`: the real spell attribute collector and real accuracy/max-hit operations follow timed Mark state under both display preferences. It verifies normal demonbane accuracy 1200 versus marked 1400 from a 1000 base roll, max 30 versus 37, and equipment-before-Mark ordering (30 → 36 → 45). One test passed; ten existing combat-formula tests also passed.
- `EnsouledHeadStorageRuntimeTest`: five actual transaction tests passed. They exercise all 23 fresh-head IDs through bank/tradeoffer insertion and return, partial quantity retention, full-container rollback, bulk deposits with different origins, uncommitted previews and ordinary inventory preservation.
- Root's `ArceuusUtilityCastRuntimeTest` executes ten utility button events and all nine resurrection button events, checking runes, XP, Book of the Dead, Prayer, and produced effects. Root's `ArceuusRuntimeTest` separately executes thrall movement, projectile, damage and lifecycle paths.
- Reanimation's nine runtime tests passed: all 46 inventory variants, all 23 fresh ground heads, tier/XP/runes, ownership, persistence boundaries and attributed kill hooks. See the reanimation audit for fixture limits.
- Resurrect Crops' two actual-handler tests and one probability test passed, exercising persistent FarmingService state, success/failure, invalid targets and single-attempt behavior.
- Minigame Teleport remains registered only by ClanMayhemWorld. Its original outside-match no-op now opens the existing generic chooser for Pest Control and Giants' Foundry, using existing supported content coordinates and the shared resting sequence. All four books share native timer varp 888, separately from Home's varp 892. The native cache has all 21 destination labels in DB table 214 and correctly matching interface 951 children 5–25; an earlier packed-ID arithmetic error was corrected. Native menu layout, the other 19 destinations and their access restrictions remain open.

Runtime deployment, startup marker verification, doctor output, and two controlled restarts are tracked by the root audit. These tests do not substitute for that requirement.

## Concrete findings and source boundaries

1. **Ward was controlled by a display setting.** StandardPlayerHitModifier originally checked `buff_ward_of_arceuus_disabled == 1`, giving damage reduction to the wrong state. It now uses the same timed Ward authority as the cast effect. An absent source is no longer accidentally classified as demonic by a nullable inequality. The Wiki's Ash reference says the *reduction* is rounded down: 11 becomes 10; 1–9 are unchanged. [Ward of Arceuus](https://oldschool.runescape.wiki/w/Ward_of_Arceuus)

2. **Home lacked the resting channel and recharge.** Its short ordinary teleport was replaced by a shared interruptible 22-tick sequence with the persistent `aide_tele_timer`. Resting teleports now require 17 ticks since combat, because the generic eight-tick combat helper was shorter than the documented ten seconds. Existing Standard and Ancient Home handlers share that authority too. Cosmetic variants, including the 18-tick Speedy override, and exact stage frame timing remain outside the execution proof. [Home Teleport](https://oldschool.runescape.wiki/w/H_teleport)

3. **Dark Lure only queued one raw route destination.** That neither maintained impling following nor used the walking API, and the ordinary combat dispatch rejected implings without an Attack option. The selected registered spell now explicitly opts into non-combat impling targets; all other spells retain the ordinary restriction. DarkLureState handles timed ownership, recharge, movement, and cleanup. Normal retreat suppression is integrated into the authoritative NPC retaliation path. Precise non-impling effect lifetime, stationary-creature exceptions and full normal-retaliation execution still require focused confirmation. [Dark Lure](https://oldschool.runescape.wiki/w/Dark_Lure)

4. **Offering cooldown was nine ticks.** The June 30, 2021 change explicitly specifies instant offering and eight ticks. [Offering spells](https://oldschool.runescape.wiki/w/Offering_spells)

5. **Corruption's launch-era 33%/66% rules are obsolete.** Both now roll 50%; greater drains twice as much. Ward-protected targets preserve the attacker's armed corruption until a later eligible successful hit. The retrieved text does not explicitly establish armed-buff expiry or whether a failed 50% roll consumes it; do not label a guessed lifetime as verified. [Corruption status](https://oldschool.runescape.wiki/w/Corruption_%28status%29), [Jagex Poll 80 update](https://oldschool.runescape.wiki/w/Update%3APoll_80_ToA_Changes_%26_DMM_Tweaks)

6. **Grasp binds were not a damage-duration increase under Mark.** Mark doubles proc chance while the duration remains 2/3/4 ticks; Ward limits the victim's bind to one tick. Demonbane gains another 20 percentage points of accuracy and 25% damage under Mark, with the damage bonus after equipment. The overview combat-spell table contains inconsistent older accuracy wording; prefer the specific spell/update source. [Jagex Poll 80 update](https://oldschool.runescape.wiki/w/Update%3APoll_80_ToA_Changes_%26_DMM_Tweaks)

7. **Thralls must acquire on a splash.** Jagex explicitly fixed this in June 2021. Root added the attack-launch integration because positive damage callbacks alone cannot establish that behavior. Precise owner leash, attack LOS and individual style range remain unconfirmed by the retrieved Wiki prose; existing constants are not source evidence. [Jagex client milestone update](https://oldschool.runescape.wiki/w/Update%3ANew_Client_Features%3A_Milestone_1)

8. **Vile Vigour and Degrime timing differed.** Wiki specifies 17 ticks for Vile and 8 for Degrime; root corrected both. Vile remains capped to the Prayer needed to fill run energy. The direct Wiki retrieval was an old September 2024 revision saying “all” Prayer, while a current third-party Wiki mirror explicitly described capped consumption. The mirror is not accepted as primary proof, and the older text is too ambiguous to justify destroying excess Prayer. Exact surplus-Prayer behavior remains a capture/source question. [Vile Vigour](https://oldschool.runescape.wiki/w/Vile_Vigour), [Degrime](https://oldschool.runescape.wiki/w/Degrime)

9. **Reanimation definitions retained older per-creature Magic XP and put dog in Basic.** Current tiers award 32/80/138/170 XP; dog belongs to Adept. Parallel agent handles provenance, locality, tier repairs and persistence testing. [Arceuus spellbook](https://oldschool.runescape.wiki/w/Arceuus_spellbook)

10. **Resurrect Crops must preserve a single attempt.** Failure clears the crop; the chance scales from 50% at 78 to 75% at 99. Native FarmingService persists `resurrected` alongside the crop. The wider farming growth model, Hespori and anima exceptions are not established by the basic probability tests. [Jagex Necromancy Improvements](https://oldschool.runescape.wiki/w/Update%3ANecromancy_Improvements)

11. **Minigame menu was absent outside Clan Mayhem.** March 2026 adds the dedicated menu and the Bounty Hunter, Mastering Mixology and Sorceress's Garden destinations. A custom match return is a separate intentional local behavior that must stay within the existing single registration. [Jagex Getting Around follow-up](https://oldschool.runescape.wiki/w/Update%3AMore_from_the_Getting_Around_Poll)

12. **Shared Teleport to Target has no gameplay handler located.** The registry acknowledges its default spellbook id, but no cast destination/target logic was found. OSRS uses a Bounty Hunter target in the Daimon's Crater; ordinary world teleport tests cannot establish that feature. [Teleport to Target](https://oldschool.runescape.wiki/w/Teleport_to_Target)

13. **Duration source distinction:** Shadow Veil and Ward use base Magic. Shadow's March 2023 Mod Ash reference was verified in the root audit. The native revision-240 Ward reader script 5940 reads its start from slot 522 and base Magic using opcode 3306/stat 6; this resolves the Wiki's less precise wording about Magic at casting. Root aligned Ward's cast duration and native timer writer accordingly. [Shadow Veil](https://oldschool.runescape.wiki/w/Shadow_Veil), [Ward of Arceuus](https://oldschool.runescape.wiki/w/Ward_of_Arceuus)

14. **Economic storage removes fresh-head locality permanently.** Bank and price-checker insertion now normalize through the existing inventory transaction, before stack/capacity checks, using the reanimation agent's `EnsouledHeadProvenance.normalizeStored`. Failed transactions retain the original item and its locality. Deposit boxes use the same bank handler. Repository-wide source searches found no actual player Trade or Grand Exchange implementation to amend; the existing `tradeoffer` transaction container is normalized, but that alone cannot prove absent Trade/GE gameplay.

15. **Mark's real formula collector also read a display preference.** The combat spell effect had timed Mark state, but `CombatMagicAttributeCollector` still checked `buff_mark_of_darkness_disabled`. It now reads the same timed state as the cast. Duke's separate Ward reduction also used the wrong floor-of-final-damage calculation; its narrow correction now subtracts the floored reduction, like the tested standard hit path.

16. **Shadow Veil must roll before the necklace and preserve its charges on a Veil save.** The sole thieving handler previously used one combined 36.25% roll and never consumed necklace charges. It now rolls Veil's 15% first, lets the NPC shout only if that fails, then rolls the necklace's 25%. Only a necklace save consumes one of ten persisted player charges; the tenth save removes the worn necklace. Four actual pickpocket coroutine tests cover these branches, expiry, replacement and persistence; combined verification is pending. [Thieving training, Mod Ash 25 June 2021 reference](https://oldschool.runescape.wiki/w/Thieving_training)

17. **Master Combat Achievement thrall duration bonus remains unavailable.** The 25 June 2025 update moved the double-duration reward from Grandmaster to Master and removed the old Master 50% bonus. Native `ca_tier_status_master` exists (12867), but no authoritative reward-tier writer, reader or claim service was found. `ClueScrollDropChecks.hasUnlockedMasterCombat()` returns unconditional `true`, while Slayer bracelets use a constant `false` for Elite completion. Neither is valid completion authority. No new CA subsystem or guessed native-state interpretation was introduced. [Jagex Summer Sweep Up: Combat](https://oldschool.runescape.wiki/w/Update%3ASummer_Sweep_Up%3A_Combat)

18. **Thrall immunity data and protected bosses have different evidence.** Custom `param.thrall_immunity` is declared with default 0 in `.data/raw-cache/server/param.toml` and exposed by `BaseParams`, but has no production consumer or raw NPC override located. The native gameval binary has no such entry. Loaded custom NPC parameter values were not independently enumerated, so this does not claim every value is zero. Thrall hits do use `StandardNpcHitModifier`: DT2's registered modifier blocks non-owner hits and inactive encounter states (`Dt2EncounterManager.modifyNpcHit`), and Yama's registered modifier blocks nonparticipants and noncombat phases (`YamaEncounterManager.modifyNpcHit`). Those concrete guards are present; universal boss-immunity parity has not been established.

## Read this before claiming 1:1 parity

Wiki pages are not all synchronized: broad overview tables sometimes retain older XP, accuracy, or Combat Achievement text. Some direct pages were blocked from retrieval; specific accessible spell pages and dated Jagex changes take precedence. This document records unresolved points instead of silently filling them from server constants. Exact audiovisual frame offsets, cosmetic teleport overrides, all minigame access restrictions, later quest/item upgrades, all farming patch exceptions, and the listed combat edge cases still require direct evidence and/or end-to-end checks.
