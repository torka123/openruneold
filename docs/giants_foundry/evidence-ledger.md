## Required resolutions before “1:1” sign-off

1. Measure whether each quality-damage event is `-10`, whether the `-5 per mistake` statement refers to a different counter, or whether one source line is stale.
2. Measure exact heat-change curves for waterfall, lava, quench, and dunk.
3. Measure exact temperature-band endpoints across material score/difficulty and their inclusive/exclusive comparisons.
4. Measure the bonus prompt lifetime, exact progress bonus, exact quality recovery, and selection/distribution algorithm after the 2025-05-07 update.
5. Capture the complete current base-client mould interface and reward-shop purchase/buyback path.
6. Resolve visible fractional-XP rounding using the target's shared XP accumulator rather than adding an activity-specific rounding policy.

No production value should be invented to close one of these gaps. A temporary implementation must be feature-flagged or explicitly documented as non-parity.
