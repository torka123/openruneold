Method:
- Git endpoint diff: git diff --no-renames --numstat 798b8c320 377c48f43
- Production Kotlin: module src/main/**/*.kt.
- Test Kotlin: module src/test/**/*.kt.
- Other: module build files and module-local documentation.
- Physical lines include comments and blank lines; these are NOT executable
  statement counts. Kotlin build scripts are in "Other," not gameplay.
- Additions + deletions = changed-line churn, not unique rewritten lines.
  Moved/extracted code can count as both deleted and added.
- The manager metric includes production files ending Manager.kt or Timeline.kt.
  Retained specialized coordinators are not automatically architecture defects.
- Documentation/scripts/shared integration outside a boss module are counted
  separately, not charged repeatedly to each boss.
- Uncommitted .data work, ignored logs/caches/PostgreSQL/build outputs, raw evidence
  and this newly created report are excluded from the committed endpoint totals.
- The committed +18 NPC overlay lines are intentional KC metadata changes for
  Guardians/Zulrah/Muspah, distinct from the current unrelated dirty .data hunks.
