# Daily Adventure task placeholder sprites

The native Adventure Paths task rows remain the temporary icon source. Real Daily tasks are placed
into fixed difficulty slots, so the placeholder shown for a task is determined by its generated
slot, not by the task definition. These are revision-240 raw sprite references decoded from stock
Adventure Path structs and clientscript 2979:

| Daily slots | Difficulty | Current placeholder sprite reference |
|---|---|---|
| 1-3 | Easy | raw sprite `197` (stock Attack task icon) |
| 4 | Easy | raw sprite `198` (stock Strength task icon) |
| 5-6 | Medium | raw sprite `198` (stock Strength task icon) |
| 7-8 | Medium | raw sprite `199` (stock Defence task icon) |
| 9 | Hard | raw sprite `199` (stock Defence task icon) |
| 10 | Hard | raw sprite `200` (stock Ranged task icon) |

Accordingly, the per-task placeholder reference below lists every sprite the task can currently
receive. This is intentionally a ledger for later art assignment; it is not a claim that the
placeholder represents the task.
